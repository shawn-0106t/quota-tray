Quota Tray — panel design A/B/C/D

Same information architecture and geometry in all four: 424px window (368px card + 28px shadow room), provider tabs, shared 4-button footer, content-driven height. Only the skin differs. Switch theme / provider / data state below — every iframe reloads together.

A — paper + hairline (Kimi app tokens)

Reads as: a Kimi product surface. Warm paper ground, alpha-black label tiers, one hairline-separated sheet, blue reserved for the active provider + limit bars. Cost: the two brand blues coexist in the tab bar (declared exception); mono is not used, so numbers lean on weight and size only.

B — dark performance spec (porsche.cn case)

Reads as: an instrument. Zero radius, 1px seams, Consolas micro-labels, 800-weight tabular numerals, one red accent that only appears on real signals. Cost: square corners on a floating tray popup is an opinionated choice; the light variant is a derived daylight sheet, not the case's native mode.

C — engineering rationalism (claude.com structure + Kimi app palette)

Reads as: drafting paper. Etched readout fields, full-width segmented pill, mono for every number and reset countdown, sans for labels, Kimi blue on limit bars and the tinted chip. Health states are two-state — only failures get colour. Cost: the two-row header makes it the tallest of the three (~45px over A), and mono numerals narrow the gap between "data" and "code".

D — C's structure + A's type + A's palette, slimmed

Reads as: C's two-row header and bare readout columns (no fill, no frame), A's all-sans type (30px semibold tabular numerals, uppercase tracked micro-labels), and A's warm paper palette cut to two hues: Kimi blue and one danger red. The tab control mirrors a reference segmented control — grey track, equal cells, active tile marked by a hairline ring (no shadow). DeepSeek's bars use the same Kimi blue, so the whole panel is one accent. Cost: the biggest type of the four, so also the tallest (~10px over C on the Kimi tab); usage percentages no longer turn red, so only real failures are coloured.

All four files are standalone (demo/panel-demo-a.html … panel-demo-d.html); each opens alone with a control bar that also reports the measured card / window height. Measured heights: python demo/heights.py.
